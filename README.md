# Финансовый анализ и ML для временных рядов

Алгоритмы предсказания и оптимизации в финансовых временных рядах.  
Основной код находится в `src`.

## Структура

- `src/data` — загрузка и подготовка данных (свечи, тикеры, dataloader).
- `src/models` — модели (`CNN`, `GRU`, `LSTM`, `Transformer`, `LightGBM`, `ARIMA` и др.), плюс `run_optuna.py` для подбора гиперпараметров.
- `src/embeddings` — эмбеддеры `Handmade_embedder.py` и `TS2Vec_embedder.py`.
- `src/evaluation` — метрики и сравнение моделей.
- `src/clustering` — `KMeans`, `HDBSCAN`, `UMAP` и анализ кластеров.
- `src/loaded_models` — сохраненные веса:
  - `full_data_models` — основные best-модели;
  - `ts2vec` — веса и конфиги TS2Vec (`daily`/`hourly`);
  - `ts2vec_models` — облегченные/служебные веса под TS2Vec-признаки;
  - `handmade_models` — облегченные/служебные веса под handmade-признаки.
- `moex_filled` — подготовленные данные (если выгружены).
- `experiments` — экспериментальные наработки.
- `tex` — материалы для текстовой/научной части.

## Быстрый старт

1. Установить зависимости:

   ```bash
   pip install -r reqirements.txt
   ```

2. Подготовить окружение:
   - при необходимости скопировать `.env_example` в `.env`;
   - проверить пути к данным и моделям в используемых скриптах.

3. Использовать модули из `src` как Python-пакет и загружать готовые веса из `src/loaded_models`.

4. Для экспериментов запускать подбор гиперпараметров через `src/models/run_optuna.py` и сравнивать результаты через `src/evaluation`.

## Примечания

- В проекте есть как полные веса (`full_data_models`), так и более легкие файлы в `ts2vec_models` и `handmade_models` для быстрых тестов.
- Если веса не загружаются, проверь соответствие имени файла и архитектуры модели.
